# Open Mafia Skill

Open Mafia Skill — открытая рейтинговая система для спортивной мафии.

## Для чего это

Система оценивает силу игрока по результатам турниров. Она рассчитана на формат спортивной мафии: стол из 10 игроков (1 дон, 2 мафии, 1 шериф, 6 мирных), командный результат каждой игры и индивидуальная оценка судьи.

Каждая игра оценивается с двух независимых сторон:

- **насколько хорошо сыграл игрок** — по судейским баллам в сравнении с остальными игроками за столом;
- **победила ли его команда** — в сравнении с тем, насколько вероятной была эта победа с учётом силы игроков и команд.

Оба сигнала сравниваются с тем, чего ожидал текущий рейтинг игрока: сильный игрок получает меньше за победу над слабыми соперниками, слабый — больше за неожиданный успех.

Система работает с играми разных судейских систем (`iMafia`, `FIIM`, `EG`, `CLM`, `MafGame`, …) и калибруется под каждую отдельно. Если судейская система в какой-то период ненадёжна, её баллы не учитываются и используется только результат игры.

## Из чего состоит

| Часть | Что делает | Документ |
|---|---|---|
| Рейтинг **«Вклад»** | Оценивает качество игры по судейским баллам: попарное сравнение с каждым игроком за столом, с учётом того, насколько детально судья оценил эту игру | [CONTRIBUTION_RATING_MATH.md](doc/ru/CONTRIBUTION_RATING_MATH.md) |
| Рейтинг **«Победа»** | Оценивает командный результат относительно ожидания: асимметрия ролей (чёрные против красных), личная сила и сила команды | [WIN_RATING_MATH.md](doc/ru/WIN_RATING_MATH.md) |
| **Объединение** | Сводит оба рейтинга в рейтинги по ролям (дон, мафия, шериф, мирный) и единый рейтинг `overall` | [COMBINE_RATING_MATH.md](doc/ru/COMBINE_RATING_MATH.md) |
| Конфигурация | Параметры движка и калибровка по судейским системам: [`global_params.json`](config/global_params.json), [`seasons_params.json`](config/seasons_params.json) | [config/](config/) |
